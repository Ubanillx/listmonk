# 客户回信邮箱任务走查（开放探索）

## 产品理解与路径

这是 listmonk 的邮件营销管理后台；使用者是管理发送和客户回信的管理员。我从个人资料页选择配置一个可用于客户回复的邮箱地址，随后查看自动检测回信的设置风险。

结果：主任务完成。实际路径：登录隔离站 `http://127.0.0.1:9273/admin/user/profile` → 个人邮件配置 → 客户回信邮箱“新建” → 填写 `qa-replies@example.invalid` 和 `QA Replies` → 设为默认 → 保存配置 → 看见“回信邮箱已保存”与“回信地址可用” → 打开自动检测回信查看条件 → 关闭开关 → 刷新并重新进入个人邮件配置，地址、默认状态和关闭的检测开关仍在。隔离测试数据保留，供复核。

关键证据：[初始配置](02-mail-settings.png)、[新建表单](03-new-reply.png)、[保存后](05-saved.png)、[检测开启全卡片](06-detection-on-full.png)、[检测关闭](07-detection-off.png)、[刷新后](08-after-refresh.png)、[手机视口](09-mobile.png)。桌面主路径按 1440×1000 操作；全卡片证据临时扩展到 1440×1600，手机为 390×844。

## 关键体验障碍

1. **未保存且未验证连接的状态显示“已验证”，容易误判自动检测可用。** 事实：保存地址时卡片标记“回信地址可用”。之后只打开“自动检测回信”开关，卡片立刻改为“已验证”，同时表单显示“有未保存的修改”，密码为空，“测试连接”和“检测最新一封”不可用；没有发起任何收件连接测试。关闭开关后标记恢复“回信地址可用”，刷新也维持原状态。[开状态证据](06-detection-on-full.png)、[刷新证据](08-after-refresh.png)。推断：“已验证”可能指另一种内部状态，但在此位置会被理解为收件连接已验证。建议结果：标记明确区分“回信地址已保存”和“收件连接已验证”，未配置/未测试时不要展示后者。

2. **收件服务器预填与邮箱域名无关的具体主机。** 事实：打开检测后，邮箱为 `qa-replies@example.invalid`，IMAP 服务器输入框已填 `imap.263.net`，端口为 993，登录账号预填为邮箱地址；页面没有说明该服务器为何适用于当前地址。[完整检测表单](06-detection-on-full.png)。推断：管理员可能顺着预填值保存错误配置，或停下来查证该值是不是推荐设置。建议结果：未知邮箱服务商时将服务器留空并清楚提示需要所属邮箱服务商提供的地址；若能可靠识别域名，才填匹配值。

## 核对边界

未填写真实邮箱密码，未保存检测开启状态，未连接 IMAP，未发送邮件，未开启 AI/退信处理。没有验证实际邮件接收或处理。保存成功除了页面提示，还通过刷新后仍存在的地址、名称、默认状态和关闭的检测开关核对。未测试真机触觉、声音或真实用户表现。
