# 发件服务自动拉黑

意图：存量产品新增功能；方案已确认，沿用 Vue 2/Buefy 和现有发件服务视觉系统。

平台管理员从第五个页签进入（投递日志之后、账号设置之前），分别管理全平台私域（个人及组织）与共享公海两套规则。默认关闭；默认类型 1/3/6/8/9，投诉可选。独立保存开关、错误类型、每日时间/间隔、回查天数、排除邮箱。

流程：修改规则 → 预览命中与跳过原因 → 保存启用；保存禁用无需预览。立即执行只使用已保存规则并要求新预览。展示执行历史及分页明细。改草稿使旧预览失效，失败保留输入，版本冲突提示重新载入。不会因打开页面自动拉黑。

全平台私域黑名单沿用退订列表关系语义；公海联系人黑名单影响所有组织。排除邮箱独立配置并在人工恢复前可加入，避免下轮回查再次拉黑。

界面：两个并列规则面板，桌面并排，窄屏单列；勾选项两列、窄屏单列。操作区和运行状态就近显示，分页明细用中性表格。复用按钮加载态、焦点和页签反馈，不新增装饰动效。

验收：管理员入口/接口边界、两套规则隔离、先预览后启用、修改使预览失效、刷新读回、查询失败零写入、重复执行幂等、定时锁与重启恢复、桌面及390px操作可达。
