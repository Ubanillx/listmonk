# 第二批平台 UI：任务走查 / 复核

复核对象：维护页的历史营销统计清理预览、筛选与删除确认。独立 IAB 临时标签页 ID `1`，入口 `http://localhost:8181/admin/settings/maintenance`；管理员会话，桌面 1440 × 900，移动 390 × 844。只打开确认并取消，未执行删除、保存设置或其他副作用操作。结束时恢复 1440 × 900 并关闭该标签页。

## 逐项核对

1. **日期输入与真实清理边界的精度不一致：修好。** 输入仍按日期显示 `2026年10月24日`，但页面顶部明确写明按 `Asia/Shanghai` 的 `00:00` 计算且不包含所选日期当天；预览和确认均显示 `创建时间早于 2026年10月24日 00:00`。所选日期全天不会进入本次清理，输入粒度与执行规则可对应。见[桌面确认](evidence/maintenance-recheck-desktop.png)、[筛选确认](evidence/maintenance-recheck-filter.png)。
2. **破坏性操作前只能核对汇总，无法检查具体记录：没修。** 默认“所有”预览仍只有 2 条汇总（浏览 1、点击 1）；改选“营销活动浏览量”后是 1 条（浏览 1、点击 0）。确认框只重复类型、数量与边界，页面和确认框均没有可辨认这 1 条所属活动的明细或记录入口。见[筛选确认](evidence/maintenance-recheck-filter.png)。

## 路径与新增问题

连续点击“刷新预览”后保留 2 条结果；打开“所有”的确认并取消，再切换“营销活动浏览量”，页面自动统计到 1 条；再次打开确认并取消。移动视口再打开同一筛选的确认，正文和取消、确认按钮均可见，取消后筛选状态仍在。统计期间在原位置显示等待状态并暂时禁用删除。见[移动确认](evidence/maintenance-recheck-mobile.png)。该路径未观察到由本批修改直接引入的卡住、走错或状态丢失。
