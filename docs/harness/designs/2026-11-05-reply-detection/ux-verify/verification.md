# 客户回信邮箱 UX 复核

按上一轮任务路径，在隔离站 `http://127.0.0.1:9273/admin/user/profile` 的 1440×1000 主视口实际操作。登录后进入“个人邮件配置”，查看现有 `QA Replies` (`qa-replies@example.invalid`)，开启“自动检测回信”，检查状态和收件连接，再关闭、刷新。手机 390×844 另取同一开启状态截图。未保存开启状态，未填密码、连接 IMAP 或发送邮件。

## 逐项核对

1. **未保存状态误显“已验证”：修好。** 开启后卡片标签是“待保存”，其下明确显示“有未保存的修改”；“测试连接”和“检测最新一封”均禁用，没有出现“已验证”。[桌面完整卡片](desktop/page.png)、[手机完整卡片](mobile/page.png)。关闭后卡片恢复“回信地址可用”；刷新后仍是该标签，检测开关关闭。
2. **未知域名预填 `imap.263.net`：修好。** 开启后 `IMAP 服务器` 输入值为空，显示灰色占位例子 `imap.example.com`，不是实际已填主机。邮箱仍为 `qa-replies@example.invalid`；登录账号预填该地址，端口 993，文件夹 `INBOX`。[桌面完整卡片](desktop/page.png)。

## 路径与边界

路径连贯：个人资料 → 个人邮件配置 → QA Replies → 开启 → 关闭 → 刷新。刷新后地址、名称、默认标记和关闭的开关仍在。本批修改直接引入的卡住、误导或状态丢失未观察到。没有验证真实收件连接、检测处理、保存开启配置或真机行为。桌面及手机截图取自本轮可操作页面；后续尚未重建的文字可读性调整不包含在这些截图中。
