# 第二批高优先级整改：实施与验收

已完成本批三项：待转移资源的真实清单与数量、维护清理的真实数量、可视化编辑器中文化。沿用现有蓝白后台和原组件，未更改资源转移、同邮箱合并、删除条件或邮件发送规则。

## 最终行为

| 页面 | 已实现 | 关键边界 |
|---|---|---|
| 管理组织 → 待转移资源 | 自动显示五类数量、总数、分页名称清单、原所有者和待转移时间；接收人与转移按钮位于清单上方，首屏可找到 | 仅所选活动组织中无所有者且已标记待转移的资源；不返回客户邮箱/属性、模板正文和媒体地址 |
| 维护 | 按客户类型、订阅条件和统计类型自动查询真实数量；统计另显示浏览/点击明细数量 | 全平台范围与原清理动作一致；单位分别为客户、订阅关系和统计记录，客户数不混入关联行 |
| 清理与转移确认 | 打开确认前重新查询，标题和确认按钮说明具体动作，默认焦点为取消；取消保留选择 | 查询快照不会锁定后续写入，执行时重新匹配，数量可能变化 |
| 日期条件 | 日期按部署时区00:00计算，排除所选日期当天；预览与确认显示精确边界 | 日期选择器的浏览器日历字段转换为部署时区，不受操作者浏览器时区影响 |
| 可视化邮件编辑器 | 工具栏、整体样式、十类内容块、属性、字体、颜色、辅助动作及导入错误中文化；跟随平台语言 | 保留已有正文、链接、JSON字段、块类型和模板表达式；英文界面继续可用 |
| 手机编辑器 | 工具栏可见，设置面板全宽并提供“返回画布”；取消/保存可通过宿主表单滚动到达 | 桌面保留画布与属性并列结构；没有在开发库保存临时编辑内容 |

无资源、零条、正在加载及查询失败都有独立反馈；预览未就绪、失败或零条时禁用执行。切组织/条件、重复刷新或离开页面后，旧响应不会覆盖当前结果。执行成功后重新获取预览。

清理了重复的三处预览快照说明，将其合并在页首；导入弹窗移除外部示例链接和冗余解释，只保留粘贴要求、替换后果和错误。客户级联说明收窄为可确认的订阅关系后果。空图片的编辑占位使用本地SVG和当前语言，不再依赖外部英文占位服务。
