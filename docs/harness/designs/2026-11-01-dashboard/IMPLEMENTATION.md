# 数据化仪表盘实施记录

日期：2026-11-02

## 范围与方向

- 类型：存量工作区 UI 升级，保留蓝白品牌、Inter、Buefy/Bulma、全局导航及工作区权限。
- 目标：用真实数据回答互动如何变化、哪些活动值得查看、投递异常与退订是否需要关注。
- 数据：`/api/dashboard/counts`、`/api/dashboard/charts`、工作区范围内的 `/api/campaigns`；无新增接口，无虚构增长率或示例数据。

## 交付

- 顶部五项指标；近30天“营销活动浏览趋势”和“链接点击趋势”双图；活动状态环图；活动表现横向排行；客户构成；最近5个活动的投递与退订分析；私域列表和公海统计。
- 两张趋势图分别显示实际起止日期。单图有记录日期不超过3天时使用柱形和数值标签，其余使用折线；缺失日期留空，坐标轴自动取样并隐藏重叠标签。
- 活动比较支持浏览、点击、退信、确认退订切换。投递区分已发送、待发送、无法发送；退订区分点击与确认。
- 客户环图中心使用“客户与成员合计”。私域列表堆叠仅含公开/私有，确认状态独立列出。
- 活动图内使用真实 ID，名称链接进入原活动详情；请求失败保留旧数据并提供页面内重试。
- 桌面和390px响应式布局；手机异常分析为双列卡片。仅图表绘制和指标悬停有克制动效，无整页入场。
