## 产品理解与自主任务

这是面向运营人员的客户与邮件营销平台；当前在“个人空间”，可管理客户列表、准备邮件营销活动和查看统计。结合首页的客户列表、营销活动与发送量，我选择的主要任务是：准备一封面向客户列表的营销邮件，找到收件目标、内容编辑入口和发送所需条件。

结果：部分完成。已到达新建活动表单、确认收件列表入口与当前发件条件；未创建活动、未编辑保存内容、未发送邮件。页面写明“保存后继续编辑邮件内容”，因此没有点击“继续”。个人 SMTP 池为空属于当前账号配置事实，不能据此断言产品故障。

## 实际路径与反馈

1. 仪表板：看到个人空间中的客户列表、客户、营销活动、发送量，于是展开“营销活动”。实际出现全部活动、新建活动、模板和统计等入口。
2. 进入“新建营销活动”：看到基本信息、收件客户、发件与回信、发送安排。名称与主题为空；个人 SMTP 轮询池显示 0，并提示到“个人”中配置。
3. 打开“客户列表”：实际出现分组列表、搜索框及“当前活动不能混选私域列表和公海列表”的提示。没有选择真实列表。
4. 输入无匹配示例查询 `ux-no-match-20261031`：实际出现“没有匹配的客户列表”，查询仍在输入框里；未观察到该分支的反馈障碍。证据记录未保存真实列表名称。
5. 点击顶部“内容”：弹出的收件列表收起，但仍停留在“营销活动”页，没有出现内容编辑器或就近解释。向下查看才看到“保存后继续编辑邮件内容。”和“继续”。这里发生一次犹豫：需推断顶部灰色内容入口与保存前置条件的关系；没有点击会保存的“继续”。
6. 到达安全边界：能理解需要先保存活动再继续编辑，但该走查不执行保存。

## 自主风险探针：配置发件邮箱时会不会丢失已填活动

选择原因：当前表单明确要求去“个人”中补充发件 SMTP。这条路径直接关联当前任务，而且需要离开活动页面。

操作：只在未保存的新建表单输入名称“UX 只读走查（未保存）”与主题“示例主题（未保存）” → 点击左侧“个人” → 页面进入“个人资料 / 个人邮件配置”，可见“尚未配置个人 SMTP” → 浏览器返回。

实际结果：离开时未观察到未保存提示；返回“新建营销活动”后名称与主题均为空。此处发生上下文丢失，需重复输入。未配置 SMTP、未新建邮箱、未保存任何表单。

## 关键问题（按任务影响）

### 1. 去补齐发件前置条件后，返回会丢失未保存的活动输入

**观察事实**：新建活动提示“请在‘个人’中配置或启用发件邮箱”。输入上述示例名称、主题后从侧栏进入“个人”，没有看到离开提示；浏览器返回后两个输入框为空。返回空表单见 `03-return-inputs-empty.jpg`。可访问状态中离开前名称/主题有示例值，返回后均只有占位文字。

**原因推断**：新建表单在路由切换后重新初始化，且未提供可见的草稿恢复或离开保护。只凭 UI 无法判定内部实现；没有验证刷新恢复、异常退出或已保存草稿。

**建议达到的结果**：运营人员按页面提示去配置发件条件后，能回到原活动并保留已填内容；若无法保留，应在离开前明确告知并提供可取消的选择。

### 2. 保存前顶部“内容”入口没有说明为什么无法进入

**观察事实**：新建活动顶部“内容”为灰色；实际点击后仍留在基本信息页，没有就近解释。保存前置说明位于表单底部，在本次 1265×712 视口需要向下滚动才能看见。首屏见 `01-new-campaign.jpg`，底部说明见 `02-continue-saves.jpg`。

**原因推断**：前置条件与被阻止的入口相隔较远，用户可能把灰色入口理解为可切换标签后才发现没有结果。该现象在更大主视口上的可见范围未验证。

**建议达到的结果**：用户在内容入口附近即可知道先完成哪些信息、下一动作是否会保存；无需点击无反馈入口后再寻找说明。
