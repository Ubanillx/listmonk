# Engineering harness

The repository's engineering ledger is maintained in [`docs/harness/`](https://github.com/knadh/listmonk/tree/master/docs/harness). It records TODOs, plans, completed and incomplete work, technical debt, architecture pointers, and business-logic invariants.

Keep the ledger synchronized with implementation changes. The detailed architecture source of truth remains [`docs/ARCHITECTURE.md`](https://github.com/knadh/listmonk/blob/master/docs/ARCHITECTURE.md).
