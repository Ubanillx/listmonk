# Engineering architecture

For the current repository layout, runtime architecture, technology stack,
workspace authorization model, and build, test, deployment, and documentation
maintenance rules, see the versioned engineering guide at
[`docs/ARCHITECTURE.md`](https://github.com/knadh/listmonk/blob/master/docs/ARCHITECTURE.md).

Changes to implementation behavior must update that guide and any affected user
documentation in the same pull request.
