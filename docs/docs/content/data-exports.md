# 数据导出

管理员可在客户、列表、营销活动、营销统计、退信及当前组织公海管理页面点击“导出”，选择数据类型、Excel 或 CSV，并在同一弹窗查看生成进度、失败原因及下载文件。关闭弹窗不会中止生成，再次点击页面上的“导出”可查看近期同类文件（展示最近 30 个任务中的最多 5 个相关任务）。最高管理员通过工作区选择器选择目标组织；组织管理员仅导出本组织的数据，包括成员的私有列表。普通成员不能使用管理端导出，公开订阅者自助资料下载不受此规则影响。

## 范围与字段

- 客户名单：客户 ID、客户编码、公司或姓名、邮箱、自定义字段、状态、所属列表及订阅状态、创建与更新时间。一位客户一行，列表关系合并展示。
- 黑名单：当前状态为 `blocklisted` 的客户。现有数据不具备完整的拉黑原因和拉黑时间，不把客户更新时间解释为拉黑时间。
- 列表目录：列表 ID、名称、类型、状态、打码开关、所有者与创建时间。
- 一级公海联系人：仅最高管理员可导出，包括尚未分配的联系人；每个联系人与一级公海关系一行。
- 公海分配名单：当前二级分配关系，包含来源公海、二级列表、分配时间及是否已移除。
- 公海分配名单：包含当前分配状态及移除原因。转入私有列表时，手动移除并填写“转入私有”，再手动添加到私有列表；公海页面和导出展示该原因。恢复分配后原因留空。不提供独立公海转私域导出，也不自动匹配或核验私有列表。
- 退信投诉明细：逐次记录；退信客户名单：按客户、公海联系人及来源组织去重，提供筛选期间最新事件和累计次数。普通组织管理员不导出原始诊断 JSON，以免诊断中夹带受保护的真实邮箱；最高管理员可导出。退信类型和来源仍可见。
- 营销活动汇总：活动状态、开始发送时间、期间私域发送量、打开/点击次数与人数、对应比率、退信及投诉次数。比例的分母是所选事件期间的私域发送量；无分母或未启用个人追踪时留空。
- 营销行为明细：私域发送、打开及点击事件，包含客户、活动、时间和链接。必须启用个人追踪且未关闭追踪。

公海发送表目前只有累计发送状态，缺少不可变的逐条发送时间，因此单列“公海累计已发送量”，不将其混入期间私域发送量。现有退订数据没有完整的逐活动历史事件，退订次数留空。未启用追踪不等于零打开/零点击。系统发送记录不代表邮件进入收件箱。

客户名单日期按创建时间，营销行为及退信日期按事件时间；当前关系名单不使用虚构转入日期。时间和文件名均采用北京时间。列表与活动可按名称选择，客户常用高级筛选支持字段比较、`AND/OR/NOT`、`IN`、`LIKE/ILIKE`、正则比较与 JSON 字段操作；不接受子查询、函数调用或跨表 SQL。不支持的筛选会明确拒绝，不会悄悄导出全量。

## 权限、脱敏和任务

导出是组织管理员的专门能力，不授予其修改成员私有数据或使用成员资源发送的权利。一级公海及二级联系人邮箱对组织管理员始终打码；私有名单按列表打码设置保护邮箱，自定义字段在打码客户名单中清空，防止字段副本泄露；最高管理员可导出明文。客户涉及多个列表时，只要本组织任一所属列表开启打码，就对其客户总表邮箱打码。

生成及下载均重新读取账号、组织活动状态和管理员资格。任务仅对创建它的管理员在相同工作区可见。列表打码、归属或追踪设置变化会使旧文件不可下载，需重新生成。文件生成完成后保留 7 天，过期后由后台下一轮清理内容块（空闲时每 3 秒轮询，正在生成任务时待其结束），任务元数据保留用于审计；服务停止期间在下次启动清理。审计记录包含创建人 ID、工作区、筛选条件、文件名、行数、创建/完成/过期时间以及成功下载次数和最近下载时间。

每位管理员最多 3 个排队/生成中任务；单个文件最多 100 万行、256 MiB 原始文本，生成超时为 20 分钟。超过限制请缩小时间/列表范围。Excel 单元格超过 32767 字符时明确失败，应选择 CSV。CSV 使用 UTF-8 BOM 和公式防注入转义；Excel 文本值按字符串写入，保留客户编码前导零。

## API 与运行

- `GET /api/exports/options`：当前管理员可筛选的列表和活动名称。
- `POST /api/exports`：创建任务，返回 202。请求包含 `type`、`format`、`search`、`query`、`list_ids`、`campaign_ids`、`ids`、`status`、`subscription_status`、`source`、`bounce_type`、`from`、`to`；时间使用带时区的 RFC3339。数组为数值 ID。`ids` 表示当前导出类型对应的行实体 ID。
- `GET /api/exports?page=1`：每页 30 个本人任务。
- `GET /api/exports/:id/download`：下载完成且未过期的本人文件。

沿用工作区请求头 `X-Listmonk-Organization-ID`。个人 API Key 不开放这些新端点。最高管理员跨组织时显式选择一个组织，避免把多个组织的名单混在同一文件。

v6.28.0 新增 `data_export_jobs` 与 `data_export_chunks`。后台 worker 随主服务启动，通过 PostgreSQL session advisory lock 保证多个实例只有一个生成者；进程中断释放锁后可重试未完成任务。数据在只读一致性事务内流式读取，使用受限临时文件与 Excelize 流式写入，最终以 1 MiB 内容块持久化到数据库，全部写入成功才公开下载。部署无需新增端口或存储卷；数据库备份和容量规划应包含七天的导出文件。

验证：`go test ./...`；设置 `EXPORT_TEST_DSN` 后运行 `go test ./internal/dataexport -v`，测试创建独立 schema，不修改原有业务数据。浏览器测试 `frontend/cypress/e2e/exports.cy.js` 使用 `EXPORT_E2E`、`EXPORT_QA_USER`、`EXPORT_QA_PASSWORD` 显式启用，不运行数据库重置命令。
